# Pragma Systems — 15 Industry Section Folders & Image Guide

Each of the **15 Industry Sections** has its own dedicated folder in `public/images/industries/`.

Simply drop your image file into the folder corresponding to the section.

---

## Quick Rule (Simplest Way)

Inside any section folder, just name your images:
* **`1.png`** (or `1.jpg` / `1.webp`) → **Block 1**
* **`2.png`** (or `2.jpg` / `2.webp`) → **Block 2**
* **`3.png`** (or `3.jpg` / `3.webp`) → **Block 3**
* **`4.png`** (or `4.jpg` / `4.webp`) → **Block 4**

*(Descriptive names like `doctors-clinics.png` or `01-1-doctors-clinics.png` also work automatically!)*

---

## Image Specifications

* **Grid Layout**: 2 Columns (Desktop) / 1 Column (Mobile)
* **Aspect Ratio**: **16:10**
* **Recommended Resolution**:
  * **1280 × 800 px** *(Ideal balance of sharpness and fast load time)*
  * **1600 × 1000 px** *(Ultra-crisp for 4K / Retina displays)*
* **Minimum Resolution**: **800 × 500 px**
* **Supported Formats**: `.png`, `.jpg`, `.jpeg`, `.webp`

## How It Renders

* If no image has been added yet, a clean architectural placeholder is shown.
* As soon as you add an image matching any of the filenames (e.g. `1.png` or `1.jpg` in that folder), the website instantly displays the image with interactive 3D physics!
